# Page Override: Version History (модалка «История версий BPMN»)

> **Статус:** override активен. При реализации этой поверхности правила данного
> файла **превалируют** над `design-system/processmap-to-be/MASTER.md`
> и над любым выводом генератора ui-ux-pro-max.

## Почему override

Генератор ui-ux-pro-max для этой поверхности предлагает glassmorphism,
оранжевый акцент и шрифт Plus Jakarta Sans. Это **отклонено**: противоречит
MASTER.md (navy/green-палитра, Fira Sans/Fira Code, плотный dashboard-стиль).
Для модалки истории версий первичен MASTER.md без исключений из палитры.

## Что берём из MASTER.md (без изменений)

- **Палитра:** primary navy `#1E3A5F`, accent/CTA emerald `#059669`,
  destructive red `#DC2626`, поверхности `#FFFFFF` на bg `#F8FAFC`,
  border `#E4E7EB`. Фиолетовый `--pm-tobe-assistant` **запрещён**
  (резервирован для PROCESSMAN, не для семантики diff).
- **Типографика:** Fira Sans (UI, заголовки панелей), Fira Code
  (хэши, XML-режим, метаданные версий). Mood: «строгий, но мягкий»
  (Linear / GitHub Insights / Notion).
- **Скругления:** 8–12px (карточки версий 12px, кнопки 8px); тени
  `--shadow-sm/md`; переходы 150–250ms.
- **Тёмная тема обязательна:** превью-вьюверы bpmn-js переводятся
  на токены темы через scoped `bpmn-version-preview.theme.css`
  (default-light рендер внутри тёмной панели — баг, не фича).

## Легенда diff (семантические цвета сравнения)

Легенда сравнения версий — единственное место, где палитра MASTER.md
расширяется семантическими «soft»-оттенками (фоновые заливки маркеров):

| Состояние | Цвет | Hex | Применение |
|---|---|---|---|
| Добавлено | emerald (accent) | `#059669` | Маркер/бейдж `added`, заливка `emerald soft` в XML-режиме |
| Удалено | rose | `#E11D48` | Маркер/бейдж `removed`, заливка `rose soft` в XML-режиме |
| Изменено | amber (warning) | `#B45309` (light) / `#F59E0B` (dark) | Маркер/бейдж `changed` |

**Контраст:** маркеры имеют форму и текстовую подпись, не цвет единый.
Текст на «soft»-заливках — только основной `--foreground`/`--text`
(≥ 4.5:1); белый текст допускается только на полных заливках
emerald `#059669` / navy `#1E3A5F` (контраст ≥ 4.5:1 проверяется
существующим `dark-theme-contrast.test.mjs`).

## Анти-паттерны (наследуются из MASTER.md, применяются строго)

- ❌ Нативные браузерные диалоги (`confirm`/`alert`/`prompt`) — только
  inline-подтверждение в шапке панели.
- ❌ Эмодзи как иконки — только SVG (Heroicons/Lucide-стиль).
- ❌ Невидимые focus-стили; layout-shifting hover; мгновенные смены
  состояния без transition 150–300ms.
- ❌ Стекло/размытие как основной стиль карточек версий.
- ❌ Оранжевый акцент генератора и Plus Jakarta Sans — в этом контуре
  не использовать ни в одном состоянии.

## Проверка перед сдачей

- [ ] Палитра/шрифты соответствуют таблицам выше (светлая + тёмная темы).
- [ ] Легенда diff читается не цветом единым (форма + подпись).
- [ ] Контраст ≥ 4.5:1, `prefers-reduced-motion`, видимые focus-стили.
- [ ] Превью-вьюверы в тёмной теме не «светят» default-light.
