## Что сделано

### 1. Редизайн страницы входа
- `PublicHomePage.jsx`: раскладка «бренд-панель + карточка» (десктоп — две колонки, мобильная — одна колонка без горизонтального скролла): логотип, PROCESSMAP, оверлайн «Food Process Copilot», теглайн, ключевые возможности.
- Режимы `login` / `invite-entry` / `invite-activate` приведены к единому визуальному языку; ошибки — inline с `role="alert"`.
- `LoginForm.jsx`: поля на едином классе дизайн-системы (`input h-11` — focus/error-кольца из токенов); поведение, autofocus, контракты и `data-testid` сохранены; совместимость с `LoginModal` и `LoginPage`.
- `LoginModal.jsx`: карточка приведена к тому же языку.

### 2. Светлая тема по умолчанию
- Новый `lib/theme.js`: `resolveInitialTheme` — дефолт `light`; тёмная только при явно сохранённом выборе (`fpc_theme=dark` продолжает работать).
- `main.jsx`: FOUC-инициализация до рендера, `catch` → `light`.
- `TopBar.jsx`: стейт тумблера инициализируется из фактического класса корня (catch → `light`), запись через единый константный ключ.

### 3. Меню аккаунта
- Шапка: аватар с инициалами, имя, email (без дубля при совпадении с именем), бейджи групп, кнопка «Профиль · скоро» (`topbar-account-profile-soon` — закрывает падавший на main тест).
- Уведомления: badge непрочитанных, сводка только при наличии уведомлений (убрано дублирование «Нет уведомлений»), строки-превью с иконкой, контекстом и относительным временем, hover-токены `info`; единый empty state.
- Контролы: иконки у «Тема» и «Выйти», разделители, logout на danger-токенах. Все `data-testid` постановки сохранены, клик-семантика не изменена, центр уведомлений не перерабатывался.

### 4. Логотип bpmn.io скрыт с канваса
