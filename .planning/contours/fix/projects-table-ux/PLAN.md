## Что переносим из прототипа
1. **Дерево с направляющими линиями**: вертикальные гайды по уровням; у листовых строк (сессии) — колено-коннектор к родителю. Шеврон только у узлов с детьми.
2. **Два шаблона строки**:
   - Контейнерные (раздел/папка/проект): полная высота, все колонки.
   - Листовые (сессии): компактные (~34px), только название, статус, дата.
3. **Тип сущности — тег после названия** (Раздел/Папка/Проект), с иконкой перед названием. Колонка «Тип» в шапке убирается — тип визуально находится в колонке «Название».
4. **«Не назначен» удалён**: пустой ответственный → тихое «+ Назначить», видимое по ховеру на строку.
5. **«Открыть →» у проектов** видимо постоянно (не по ховеру). Меню «···» всегда в конце строки.
6. **Колонка «Обновлено» двухстрочная**: относительное время (до 7 дней, дальше дата) + приглушённое событие с тултипом полного текста.
7. **Прогресс «Состав»**: bar + «done/total» с тултипом «Заполнено X из Y узлов (Z%)». Нулевой прогресс не рисует ложную заливку.
8. **Работающие**: сворачивание веток, фильтры-чипы по статусам, сортировка по «Название» и «Обновлено» внутри siblings, поиск по всем уровням (показ совпадений + предков + потомков, свёрнутость игнорируется).
9. **Sticky-заголовок таблицы** при скролле.

## Что НЕ переносим
- Цвета, фоны, радиусы, тени, шрифты, отступы из CSS прототипа.
- Vanilla JS стек прототипа.
- Демо-данные прототипа.

## Ограничения
- Состав колонок, их порядок и названия без изменений (кроме визуального переноса тега типа в ячейку «Название»).
- Раскрытое по умолчанию состояние дерева — как сейчас.
- Верхние вкладки, сайдбар, кнопки создания, футер версии — не трогаем.
- API-контракты не меняем.
