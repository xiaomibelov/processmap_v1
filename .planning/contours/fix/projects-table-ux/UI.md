# UI.md — Экран «Проекты» после UX-переработки

## Общее
- Стиль взят из дизайн-токенов проекта (`tokens.css`), не из прототипа.
- Колонки: Название | Состав | Ответственный | Статус | Обновлено | Действия.
- Колонки «Тип» в шапке нет — тип сущности отображается тегом в ячейке «Название».

## Состояния

### 1. Дерево раскрыто (по умолчанию)
- Разделы (depth=0) — иконка папки, название, тег «Раздел».
- Папки (depth=1) — с отступом + guide-линия, тег «Папка».
- Проекты (depth=2) — с отступом + guide-линия, тег «Проект», постоянная ссылка «Открыть →», меню «···».
- Сессии (depth=3, leaf) — компактные строки (~34px), guide-линии с колено-коннектором, только название, статус, дата.

### 2. Дерево свёрнуто
- У узлов с детьми шеврон повёрнут влево; дети скрыты.
- У листьев (сессий) и узлов без детей шеврона нет.

### 3. Фильтр по статусу
- Под header появляется строка чипов: Все / Активен / Готово / Черновик / AS IS.
- Активный чип — тёмный фон, белый текст.
- При выбранном фильтре дерево игнорирует свёрнутость и показывает только совпадающие узлы + их предков.

### 4. Поиск
- Поле поиска в header. При вводе переключается на `ExplorerSearchResults` (существующий global search).
- Совпадения группируются по типам; предки/потомки показываются в результатах.

### 5. Пустой ответственный
- В ячейке «Ответственный» пусто; по ховеру на строке появляется «+ Назначить».
- «Не назначен» не отображается.

### 6. Длинные имена
- Название обрезается ellipsis; при ховере marquee-прокрутка (сохранено существующее поведение `ExplorerMarqueeText`).
- Полное название в `title` элемента.

### 7. Sticky-заголовок
- `<thead>` прилипает к верху контейнера при вертикальном скролле (`position: sticky`).
