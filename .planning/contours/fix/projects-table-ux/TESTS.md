# TESTS.md — Кейсы приёмки «Проекты»

## Ручные кейсы

### 1. Дерево и сворачивание
- [ ] Открыть экран «Проекты». Убедиться, что дерево раскрыто по умолчанию.
- [ ] Кликнуть шеврон у раздела с детьми — раздел сворачивается, дети скрываются.
- [ ] Кликнуть шеврон снова — раздел разворачивается.
- [ ] У сессий (листьев) шеврона нет.
- [ ] У раздела/папки/проекта без детей шеврона нет.

### 2. Фильтры по статусам
- [ ] Чип «Все» активен по умолчанию.
- [ ] Выбрать «Активен» — остаются проекты со статусом active и сессии in_progress + их предки.
- [ ] Выбрать «Готово» — остаются проекты done/completed/ready и сессии ready + их предки.
- [ ] Выбрать «Черновик» — остаются сессии draft + их предки.
- [ ] Выбрать «AS IS» — остаются разделы/папки с context_status=as_is + их предки.
- [ ] При активном фильтре свёрнутость игнорируется (совпадающие узлы видны даже если родитель был свёрнут).

### 3. Сортировка
- [ ] Кликнуть заголовок «Название» — элементы внутри одного родителя сортируются по алфавиту.
- [ ] Кликнуть повторно — порядок обратный.
- [ ] Кликнуть заголовок «Обновлено» — элементы внутри одного родителя сортируются по дате (сначала новые).
- [ ] Иерархия дерева сохраняется (сортировка только внутри siblings).

### 4. Поиск с раскрытием предков
- [ ] Ввести запрос в поле поиска.
- [ ] Убедиться, что показаны совпавшие узлы и их предки.
- [ ] Сбросить поиск — вернуться к обычному дереву.

### 5. Пустой ответственный
- [ ] Найти строку без ответственного.
- [ ] Убедиться, что по умолчанию ячейка пустая (не «Не назначен»).
- [ ] Навести курсор на строку — появляется «+ Назначить».
- [ ] Кликнуть «+ Назначить» — открывается диалог назначения.

### 6. Длинные имена с тултипом
- [ ] Найти строку с длинным названием.
- [ ] Убедиться, что текст обрезается ellipsis.
- [ ] Навести курсор — появляется тултип с полным названием (либо marquee, либо `title`).

### 7. Прогресс «Состав»
- [ ] У раздела/папки отображается количество проектов и bar с done/total.
- [ ] У проекта отображается bar с done/total.
- [ ] При 0/0 или 0/total bar не имеет цветной заливки.
- [ ] При наведении на bar появляется тултип «Заполнено X из Y узлов процесса (Z%)».

### 8. «Открыть →» и меню проекта
- [ ] У каждого проекта ссылка «Открыть →» видна постоянно (не только по ховеру).
- [ ] Меню «···» расположено в конце строки и доступно всегда.

### 9. Sticky-заголовок
- [ ] Добавить в workspace достаточно элементов для появления вертикального скролла.
- [ ] Проскроллить вниз — заголовок таблицы остаётся видимым у верхнего края.
