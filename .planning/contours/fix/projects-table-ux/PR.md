# PR: UX-переработка таблицы проектов (fix/projects-table-ux)

## Что сделано
Переработан экран «Проекты» (workspace-таблица) по HTML-прототипу `app/index.html`. Перенесено поведение и структура; визуальный стиль взят из дизайн-токенов проекта.

## Изменённые файлы
- `frontend/src/features/explorer/WorkspaceExplorer.jsx`
- `frontend/src/features/explorer/explorerTableFormat.js`
- `frontend/src/features/explorer/explorerColumnVisibility.js`
- `frontend/src/features/explorer/explorerAdaptive.css`

## Что реализовано
1. **Дерево с guide-линиями**: вертикальные линии по уровням вложенности; у сессий — колено-коннектор.
2. **Два шаблона строки**: контейнерные (раздел/папка/проект) — полная высота; сессии — компактные (~34px).
3. **Тип сущности — тег после названия** («Раздел»/«Папка»/«Проект»). Отдельная колонка «Тип» убрана из шапки, состав заголовков сохранён.
4. **Пустой ответственный**: вместо «Не назначен» — тихое «+ Назначить» по ховеру.
5. **«Открыть →» у проектов** видно постоянно; меню «···» всегда в конце строки.
6. **Колонка «Обновлено»** — двухстрочная: время + событие с тултипом.
7. **Прогресс «Состав»** — bar + done/total, тултип «Заполнено X из Y узлов (Z%)»; нулевой прогресс без ложной заливки.
8. **Фильтры-чипы по статусам**: Все / Активен / Готово / Черновик / AS IS.
9. **Сортировка** по «Название» и «Обновлено» внутри siblings.
10. **Sticky-заголовок** таблицы при скролле.

## Отклонения от прототипа
- Цвета, фоны, радиусы, шрифты, отступы — из дизайн-токенов проекта, а не из CSS прототипа.
- Статусы «AS IS» применяются к разделам/папкам (context_status), к проектам и сессиям — их родные статусы.
- Стек остался React + Tailwind; vanilla JS прототипа не использовался.
- Демо-данные прототипа заменены на реальные данные из существующего API.
