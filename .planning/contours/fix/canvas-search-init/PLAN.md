# PLAN: Fix инициализации поиска на Canvas

**Контур:** `fix/canvas-search-init`  
**Тип:** `fix`  
**Роль:** Agent 2 (Executor)  
**Baseline:** `origin/main` (`037ae13b608c71512606761e65e5b9674d8c9494`)

---

## 1. Баг

**Шаги воспроизведения:**
1. Открыть любую схему (Canvas / Schema view).
2. Кликнуть на поле поиска «Поиск по элементам, свойствам...».
3. Выпадает панель: заголовок «Все элементы (0)», вкладки «Элементы» / «Свойства», пустое состояние «Ничего не найдено».

**Ожидаемое:** при клике на поле поиска сразу показывается список элементов/свойств текущей схемы.  
**Фактическое:** список пуст до дополнительного клика на вкладку.

---

## 2. Что исправить

### 2.1. Автозагрузка при фокусе на поле поиска
- При `focus` / `click` на input-поле поиска сразу заполнять выпадающую панель данными текущей схемы.
- Для активной вкладки «Элементы» — показать все элементы схемы.
- Для активной вкладки «Свойства» — показать все свойства элементов схемы.
- Без необходимости дополнительного клика на вкладки.

### 2.2. Проверить логику инициализации
- Проверить, что данные не грузятся только по `onChange` / клику на вкладку.
- Убедиться, что пустой initial state заполняется при открытии панели (focus на input).
- Учесть race condition: данные схемы должны подгружаться после готовности canvas.

### 2.3. Улучшение UX (мини-фича в рамках fix)
- Показывать top-N элементов сразу (10–15 первых) со скроллом.
- Добавить кнопку/ссылку «Расширенный поиск» внизу выпадающей панели.
- При клике — расширенная панель: все свойства + таски (первые 5, с «Показать ещё»).

## 5. Критерии приёмки

- [ ] Заходим в схему → кликаем на поле поиска → сразу видим список элементов (не пустой).
