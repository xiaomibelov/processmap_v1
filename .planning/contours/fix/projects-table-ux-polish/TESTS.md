# fix/projects-table-ux-polish — тестовые сценарии

## Автоматизированные тесты

Запускаются перед коммитом:

```bash
cd frontend
npm run build
node --test src/features/explorer/*.test.mjs
```

### Покрытие существующих тестов (frontend)

- `explorerAdaptive.source.test.mjs` — адаптивная таблица, плотность строк.
- `explorerColumnVisibility.test.mjs` — видимость колонок на разной ширине.
- `workspaceAssigneePicker.source.test.mjs` — выбор ответственного в диалоге.
- `workspaceOpenAffordance.source.test.mjs` — действие «Открыть →» у проектов.
- `workspaceSectionHeaderCleanup.source.test.mjs` — заголовки секций.
- `workspaceSessionAssignees.source.test.mjs` — ответственный на сессиях (новое).
- `workspaceSortableColumns.source.test.mjs` — сортировка колонок.
- `workspaceSubprocessTreeView.source.test.mjs` — древовидное отображение сессий.

## Ручные функциональные сценарии

### 1. Геометрия дерева

| # | Сценарий | Ожидаемый результат |
|---|----------|---------------------|
| 1.1 | Раскрыть раздел с папками и проектами | Вертикальные гайды проходят через все строки одного уровня без разрывов |
| 1.2 | Раскрыть проект, содержащий сессии | У строк-сессий есть колено: вертикаль от верхней границы строки до центра + горизонталь до иконки сессии |
| 1.3 | Навести курсор на строки с зеброй | Фон зебры не перекрывает гайды; гайды остаются видны поверх фона |
| 1.4 | Прокрутить таблицу вниз | Заголовок таблицы остаётся прилипшим (sticky); содержимое ячеек выровнено с заголовками |
| 1.5 | Свернуть/раскрыть папку | Шевроны одного уровня остаются на одной вертикальной оси |
| 1.6 | Проверить на 1280px | Колонки не съезжают; колонка «Обновлено» скрыта (адаптивное поведение, не изменено) |
| 1.7 | Проверить на 1920px | Видна колонка «Обновлено»; заголовки и ячейки выровнены по базовой сетке |

### 2. Назначение ответственного на сессиях

| # | Сценарий | Ожидаемый результат |
|---|----------|---------------------|
| 2.1 | Навести курсор на строку сессии без ответственного | Появляется кнопка «+ Назначить» в колонке «Ответственный / Исполнитель» |
| 2.2 | Нажать «+ Назначить» на сессии | Открывается диалог «Исполнители схемы» с radio-списком пользователей |
| 2.3 | Выбрать пользователя и сохранить | В строке сессии отображается аватар + имя; UI обновляется без перезагрузки (оптимистично) |
| 2.4 | Перезагрузить страницу | Назначенный ответственный сохранился (персистентность через API) |
| 2.5 | Нажать на назначенного ответственного в строке сессии | Открывается диалог; можно выбрать другого пользователя |
| 2.6 | В диалоге выбрать «Очистить» и сохранить | Ответственный снят; в строке снова появляется «+ Назначить» по ховеру |
| 2.7 | Имитировать ошибку API (например, 500) | UI откатывается к предыдущему состоянию; показывается notice об ошибке |
| 2.8 | После назначения применить фильтр по статусу | Сессия остаётся в таблице, если статус совпадает; фильтр не ломается |
| 2.9 | После назначения отсортировать по «Название» или «Обновлено» | Сессия перемещается в соответствии с правилами сортировки |

### 3. Поиск и фильтрация

| # | Сценарий | Ожидаемый результат |
|---|----------|---------------------|
| 3.1 | Ввести поисковый запрос, совпадающий с названием сессии | Совпадающая сессия видна; все её предки автоматически раскрыты |
| 3.2 | Ввести поисковый запрос, совпадающий с названием папки | Папка раскрыта; видны её потомки |
| 3.3 | Нажать чип фильтра по статусу | В таблице остаются только строки с выбранным статусом (включая сессии) |
| 3.4 | Снять фильтр по статусу | Возвращается полный список с сохранённым состоянием свёрнутости |
| 3.5 | Отсортировать по «Название» | Сортировка применяется внутри siblings на каждом уровне |
| 3.6 | Отсортировать по «Обновлено» | Сортировка применяется внутри siblings; дата и событие отображаются корректно |

## Визуальный чеклист геометрии (для ревью)

- [ ] Вертикальный гайд каждого уровня — непрерывная линия через всю высоту строки.
- [ ] Колено у листовой строки: вертикаль до центра + горизонталь до иконки; угол без зазора.
- [ ] Горизонтальный разделитель строки проходит под гайдами.
- [ ] Шевроны одного уровня на одной вертикальной оси.
- [ ] Тег типа (Раздел/Папка/Проект) расположен сразу после названия.
- [ ] На 1280px ничего не «плывёт»; заголовки выровнены с ячейками.
- [ ] На 1920px ничего не «плывёт»; видна колонка «Обновлено».
- [ ] Debug-оверлей (`.explorer-debug-grid`) не применяется к `<table>` в финальном коде.
