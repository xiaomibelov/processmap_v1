# fix/projects-table-ux-polish — UI-скриншоты

## Debug-оверлей (для ревью геометрии)

Оверлей подсвечивает гайды дерева красным, границы ячеек — синим пунктиром, границы строк — зелёным точкам. Класс `.explorer-debug-grid` добавляется к `<table>`; в финальный код не коммитится.

### 1280px — раскрыта папка «Импортировано»

![1280 debug](UI_1280_debug.png)

Что видно:
- Вертикальные гайды проходят через все строки без разрывов.
- У листовых строк-проектов под «Импортировано» есть колено (вертикаль + горизонталь до иконки).
- Дочерние проекты расположены на уровне `depth=1`.
- Шевроны одного уровня на одной вертикальной оси.
- В compact-режиме (<1280) колонка «Обновлено» скрыта — это существующее поведение, не изменено.

### 1920px — раскрыта папка «Импортировано»

![1920 debug](UI_1920_debug.png)

Что видно:
- На широком экране видна колонка «Обновлено»; заголовки выровнены с содержимым.
- Геометрия дерева та же: гайды непрерывны, колена совпадают с границами строк.
- Тег типа (РАЗДЕЛ/ПРОЕКТ) идёт сразу после названия, не отдельной колонкой.

### 1920px — раскрытый проект + строка сессии

![sessions debug](UI_sessions_debug.png)

Что видно:
- Раскрытый проект «Описание процессов Долгопрудный» показывает сессию «123».
- У сессии есть колено листовой строки и отступ `depth=2`.
- В колонке «Ответственный / Исполнитель» у сессии отображается «+ Назначить».

## Чистый вид (без debug-оверлея)

Скриншоты без оверлея совпадают с текущей тёмной темой проекта; hex-значения из прототипа не используются.
