# UI.md — Единый визуальный язык сабтабов «Анализ процесса»

**Контур:** `feature/analysis-tabs-ux-overhaul-p2`  
**База:** `REGRESSION.md` (потери PR #828/#829) + `design-system/processmap/MASTER.md` + `design-system/processmap/pages/process-analysis.md` + выводы `ui-ux-pro-max`.

---

## 1. Дизайн-принципы

| Принцип | Как реализуем |
|---------|---------------|
| **Единый язык** | Все сабтабы обёрнуты в `AnalysisSection` (`frontend/src/features/process/analysis/ui/AnalysisSection.jsx`): скругление 12px, токены `--pm-tobe-*`, шрифт Fira Sans/Code, плотность 8/10. |
| **Минимум мёртвых зон** | Ни один сабтаб не остаётся пустым: либо контент, либо `AnalysisEmptyState` с primary-действием. |
| **Функциональность прежде декора** | Все элементы из `REGRESSION.md` («Mainline время», фильтры веток, collapsible таблицы и т.д.) возвращаются, но в новой визуальной обёртке. |
| **Toolbar = один источник истины** | Режимы отображения, фильтры, вторичные действия собраны в один toolbar с единым `analysisChip`. Расширенные контролы скрываются под «Дополнительно». |
| **Контраст и доступность** | Текст 4.5:1, фокус `outline: 2px solid --pm-tobe-primary`, `cursor:pointer` на всех интерактивных элементах, `prefers-reduced-motion`. |

## 7. Toolbar: единый паттерн

Для всех сабтабов, где нужен toolbar:

```
[primaryBtn]  [input.search]  [chip] [chip]  [chip ▾]  [...]
────────────────────────────────────────────────────────────
(analysisChipActive только для активных фильтров/режимов)
```

- `.analysisChip` — вторичное действие/фильтр.
- `.analysisChipActive` — активное состояние.
- Расширенные фильтры показываются только после клика «Дополнительно».
- Убираем дублирующие hint-строки внизу.

## 11. Решения по возврату функциональности

| Потеря | Решение | Почему |
|--------|---------|--------|
| Summary rich metrics | Использовать `SummaryBlock` + `AnalysisKpiCard` | Компонент уже готовит все данные, осталось стилизовать. |
| Branches filters/add/conditional | Использовать `BpmnBranchesPanel` | В нём уже есть фильтры, add-transition, grouping, badges. |
| Steps subprocess collapse / details | Вернуть `TimelineTable` для matrix view | `VirtualStepsTable` не поддерживает дерево подпроцессов и inline-детали; дешевле переиспользовать готовое. |
| Toolbar clutter | Разделить primary/advanced в `TimelineControls` | Убирает визуальный шум и возвращает старый паттерн toggle. |
| Companion collapsibility | `AnalysisSection collapsible` | Единый паттерн для всех панелей. |
| Boundaries summary position | Поднять summary над stepper | Восстанавливает навигацию и видимость сохранения. |
