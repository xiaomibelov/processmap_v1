# UI — feature/product-actions-output-v2

## Глоссарий

- **Действие** — физическое действие сотрудника с продуктом, глагольная формулировка (`action_text`).
- **Тип** — категория действия (вскрытие, перекладывание, перетаривание, нарезка, разогрев, упаковка, маркировка, другое).
- **Этап** — этап процесса (подготовка, до разогрева, после разогрева, сборка, упаковка, маркировка, финальный этап, другое).
- **Объект** — продукт/ингредиент/полуфабрикат/блюдо/тара/упаковка, с которым производится действие.
- **Способ** — инструмент/манипуляция (перелить, взять щипцами, нарезать ножом и т.д.).

## Общие принципы

- Density 8/10 (design-system/processmap/MASTER.md): рабочий инструмент-список, минимум воздуха.
- Таблица на всю ширину панели, горизонтальная прокрутка при необходимости.
- Все строки i18n в `processAnalysis.ai.*`; никакого хардкода.

## Компонент: `ProductActionSuggestionsPanel`

### Состояния панели

1. **Empty** — нет предложений, кнопка «Сгенерировать действия».
2. **Loading** — `AnalysisSkeleton`.
3. **Error** — `AnalysisErrorState` + технический код ошибки.
4. **List** — таблица предложений + сводка + массовые действия + RAG-бар.

### Таблица

| Колонка | Содержимое |
|---------|------------|
| Действие | `action_text` или маркер «уточнить» |
| Тип | чип «Тип: X» |
| Этап | чип «Этап: X» |
| Объект | чип «Объект: X» |
| Способ | чип «Способ: X» |
| Привязка | `step_label` |
| Статус | бейдж pending/approved/rejected |
| Действия | кнопки в зависимости от статуса |

### Статусы строки

- **Pending**: [Утвердить] (disabled при невалидности) [Отклонить] [Изменить]
- **Approved**: [Изменить] [Снять утверждение]
- **Rejected**: строка приглушена, [Вернуть на рассмотрение] [Изменить]

### Редактирование

- По кнопке «Изменить» строка заменяется на inline-форму.
- Поля: `action_text`, `action_type`, `action_stage`, `action_object`, `action_method`, select привязки к шагу.
- Кнопки: «Готово» (сохранить), «Отмена».

### Массовые действия

- **Утвердить всё валидное** — утверждает только валидные pending-строки.
- **Отклонить всё** — отклоняет все pending-строки.
- **Выгрузить** — dropdown CSV / Excel.

### Валидация

Строка считается валидной, если заполнены:
- `action_text`
- `action_type`, `action_stage`, `action_object`, `action_method`
- привязка к шагу (`step_id`/`node_id`/`bpmn_element_id`)

Невалидные строки помечены маркером «уточнить».

### RAG-бар

- Остаётся внизу панели без изменений.
- Показывает статус: не готова / готова / в очереди / проиндексирована.
- Кнопка «Отправить на RAG-индексацию» при статусе `ready`.
