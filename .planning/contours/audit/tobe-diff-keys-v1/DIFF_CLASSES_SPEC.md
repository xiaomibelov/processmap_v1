## 1. Классы диффа (элемент TO BE относительно AS IS)

| Класс | Имя | Критерий | Доказательная сила |
|---|---|---|---|
| **A** | Provenance/id | У элемента TO BE есть сохранённая provenance-связь с элементом AS IS (derived_from / совпадающий id) | Сильная (прямая связь) |
| **B** | Name-match | Нормализованное имя совпадает с уникальным элементом AS IS (NFKC lowercase, strip не-алфанумерики) | Средняя (контентный якорь) |
| **C** | Type/position | Совпадает тип (task/gateway/event) и ближайшая позиция по оси X среди незанятых кандидатов того же типа | Слабая (геометрическая эвристика) |
| **D** | New | Аналога нет — новый элемент TO BE | Отсутствие связи |

### Нормализация имени (v2)
`normalize(name) = re.sub(r'[^0-9a-zа-я]+','', NFKC(name).lower())`. Пустое имя не участвует в классе B.

### Приоритет
Классификация строго по приоритету A → B → C → D; каждый элемент AS IS может быть «потреблён» только один раз (greedy по порядку элементов TO BE).

## 2. Откуда берётся класс A в продукте (код)

- Бэкенд-конвейер `transform_asis` (`backend/app/transformation/pipeline.py:347,453,531`) строит draft-узлы TO BE с полем `derived_from: [as_is_element_id]` и `trace_map` (AS IS element → судьба).
- **Критический разрыв persistence:** `derived_from`/`trace_map` живут только в памяти фронтового `Workspace.jsx` (`useState`, строки 102, 556–560) и в overlay-графе. Ни бэкенд (`PUT /api/sessions/{id}/bpmn` кладёт клиентский XML as-is), ни фронтовый сериализатор BPMN **не пишут** per-element provenance в `bpmn_xml` (нет `pm:derivedFrom`/extensionElements для этого; namespace `pm:` используется только для `pm:RobotMeta`).
- Следствие: **класс A недостижим после save/reload** — восстанавливается максимум до класса B по именам. Это и определяет «provenance-first» как стратегию устранения разрыва, а не текущее состояние.

## 4. Итоговая формулировка для контура tobe-diff

- Дифф-ключи по убыванию надёжности: **B (имя, 96% покрытия у task)** → C (тип+позиция) → ничего (D).
- A требует persistence-фикса: писать `derived_from` в `bpmn_xml` (например `pm:trace` extensionElement) либо в `notes_by_element_json`/`bpmn_meta_json` при save TO BE.
- Высокий риск класса B: нормализованные имена не уникальны в больших схемах (повторы «Добавить ингредиент») → жадное one-to-one потребление обязательно; коллизии разрешаются downgrade в C.
