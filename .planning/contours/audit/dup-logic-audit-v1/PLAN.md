## Цель
Полный аудит дублирующей логики кодовой базы ProcessMap: точные клоны, структурные
дубли функций, копипаста утилит, параллельные реализации доменных API,
форк-дрейф монолит↔микросервисы, cross-layer дубли frontend↔backend.

## Метод (graph-first, AGENTS.md §8.5)
Официальный graphify-снапшот в репозитории отсутствует (`graphify-out/` — runtime-артефакт,
монтируется в compose), пакет graphify в среде аудита недоступен. Граф пересобран
локально тем же методом, что заложен в `tools/graphify-render-graph.py`:
- узлы: модули + функции + классы (Python AST — 639 файлов; Babel parser — 1047 JS/TS файлов);
- рёбра: импорты (module-level граф), определения, вызовы;
- слои по path-правилам из `tools/graphify-semantic-config.json`;
- communities: greedy modularity (networkx), hubs по degree.

Инструменты детекции дублей:
1. **jscpd** (token-based CPD, min 50 tokens / 5 lines) — точные клоны блоков.
2. **AST-фингерпринты** — нормализованный AST (идентификаторы/литералы обезличены) → sha1;
   совпадение хэша = структурный клон функции.
3. **Same-name кластеры** — функции с одинаковым именем в ≥2 файлах + подсчёт
   различных вариантов реализации (по фингерпринту) — детектор дрейфа семантики.
4. **Графовые метрики** — hubs, communities, компоненты связности, layer gaps.
