## Суть

Единая точка входа во все LLM-фичи. Кнопка «PROCESSMAN + SVG-иконка» в
ProcessStageHeader справа от «Отчёты» → панель-помощник, контент зависит от
активной вкладки.

## Кнопка

Toggle + `aria-pressed`; нажата = «утоплена» (фон `--pm-tobe-accent` 12%,
текст `--pm-tobe-fg`). Иконка — кастомный SVG 16px (узел графа + искра),
`currentColor`, `assets/icons/`. `aria-label="PROCESSMAN — ИИ-помощник по
процессу"`, видимый focus-ring. Disabled при `has_api_key=false`: тултип
«Настройте LLM-провайдера в админ-панели (раздел LLM)», доступен с клавиатуры.

## Backend

`GET /api/llm/status` → только `{configured: bool}` + `{quota: {used, limit}}`.
Доступ: technologist. Никаких секретов/моделей/провайдеров.

## Панель

Дровер справа **380px, push-layout** (bpmn.io resize); <1200px — overlay 360px
с подложкой. Закрытие: тоггл/крестик/Esc; клик по канвасу НЕ закрывает;
состояние между сессиями не сохраняется. Шапка 48px (иконка + «PROCESSMAN» +
бейдж вкладки + крестик), футер 40px (дисклеймер «Ответ генерирует ИИ ·
проверяйте перед применением» + «из кэша · 0 токенов»/«новый запрос» +
👍/👎 SVG → feedback в `llm_usage`, 👎 без комментария v1).
`role="complementary"`, `aria-live="polite"` на зоне ответа. Анимация
translateX 200ms/150ms, только transform, prefers-reduced-motion → 0ms.

## Контент (следует за активной вкладкой воркбенча)

- **TO BE** — три действия кнопками 40px (suggest-next / explain-step /
  step-qa) + последний ответ (confidence, [↻ Обновить]); шаг не выбран →
  пустое состояние; open_questions (<0.6) — компонентом LLM2.
- **Схема** — `SchemaAssistantBlock` ПЕРЕНОСИТСЯ из вкладки в панель (из
  вкладки убрать).
- **Анализ** — сводка последнего анализа + «Открыть полный анализ» (без дубля
  запуска).
- **AS IS / Отчёты** — нейтральное состояние.

Переключение вкладки меняет контент панели, панель не закрывается.

## Кэш v1 = in-memory

«Последний ответ» в памяти сессии фронта, до перезагрузки. Backend
cache-read endpoint НЕ делать. Бейдж «из кэша · 0 токенов» только на
in-memory попаданиях.

## Токены (жёстко)

Открытие/переключение вкладки/выбор шага = **0 запросов**. Запрос только по
клику на действие или ↻. Никаких авто-запросов/префетча — никогда.
Уточнение владельца (2026-08-08): 1× `GET /api/llm/status` при открытии
панели — НЕ нарушение (это не LLM-gateway, 0 токенов).

## Состояния S1–S8 (все обязательны)

| # | Состояние | Требование |
|---|-----------|------------|
| S1 | disabled без ключа | тултип, доступный с клавиатуры |
| S2 | пустое | шаг не выбран |
| S3 | кэш | in-memory попадание, бейдж «из кэша · 0 токенов» |

| S8 | бейдж fallback-провайдера | показывать, когда сработал fallback |

Минимум S1/S4/S6/S7 — тестами.
